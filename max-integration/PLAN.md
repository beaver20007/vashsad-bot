## Риск-реестр

| ID | Риск | Вероятность | Влияние | Митигация |
|----|------|-------------|---------|-----------|
| R1 | Удаление бота без причины | Средняя | Высокое | MAX = вторичный канал |
| R2 | Поломка API после обновления | Высокая | Среднее | Pin версий, логи, алерты |
| R3 | Документация не совпадает с реальностью | Гарантировано | Среднее | Логировать все ответы |
| R4 | Mini App недоступен | Факт | Высокое | Web-ссылки вместо Mini App |
| R5 | Rate limit 30 rps | Низкая | Среднее | Очередь + retry с backoff |
| R6 | Нет возможности инициировать диалог | Факт | Среднее | Собирать user_id при /start |
